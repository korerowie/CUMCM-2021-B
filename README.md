# C4烯烃收率的优化

## ——2021年全国大学生数学建模竞赛B题

**摘&emsp;要**

本文针对乙醇偶合制备C4烯烃过程中的催化剂组合与温度优化问题，建立了系统的数学模型，分别对三个子问题进行了分析与求解。

&emsp;&emsp;针对问题一，对附件1中共114组实验数据，分别建立乙醇转化率和C4烯烃选择性与温度的关系模型。采用候选模型筛选策略，对每种催化剂依次拟合线性模型、二次多项式模型和指数模型，以决定系数R²和均方根误差RMSE为评价指标，筛选出最优模型；对于呈S型变化特征的B6、A13、A3三种催化剂，单独采用Logistic模型进行拟合。结果表明，多数催化剂的最优模型为二次多项式或指数模型，拟合效果良好。针对附件2中的稳定性测试数据，对C4烯烃选择性序列进行平稳性检验，通过一阶差分分析和ADF检验判定序列近似平稳，进一步建立AR(1)和AR(2)模型，按AIC准则选得最优模型为AR(1)。

&emsp;&emsp;针对问题二，将催化剂组合中的Co负载量、Co/SiO₂质量、第二载体质量及乙醇流速等原始信息，构造出三个自变量：X₁（Co绝对质量/乙醇流速）、X₂（乙醇流速×装料总质量）和X₃（温度）。通过单因素方差分析（ANOVA）初步筛选各因素的相对重要性，结果表明温度（X₃）对乙醇转化率和C4烯烃选择性的影响最为显著，η²分别达0.912和0.835。随后，建立包含X₁、X₂、X₃、X₃²、X₁X₂、X₁X₃六项特征的多元多项式回归模型，并与引入L2正则化的岭回归模型进行对比。以全部114组数据为基础，采用5折交叉验证确定最优正则化参数λ，最终岭回归模型对乙醇转化率和C4烯烃选择性的拟合R²分别为0.9684和0.9647，显著优于普通多元多项式回归，有效抑制了多重共线性带来的过拟合。

&emsp;&emsp;针对问题三，以C4烯烃收率（收率 = 转化率 × 选择性 / 100）为优化目标，利用问题二中建立的岭回归模型作为代理模型，采用粒子群优化（PSO）算法在三维空间（X₁, X₂, X₃）中搜索最优催化剂组合与温度。分别考虑两种场景：（a）无温度限制；（b）温度低于350℃。场景（a）的最优收率为42.36%，对应温度约425℃；场景（b）的最优收率为38.52%，对应温度约349℃。PSO收敛曲线显示算法在约100次迭代后趋于稳定，具有良好的收敛性。

&emsp;&emsp;最后，对模型进行了残差分析、交叉验证和敏感性检验，验证了模型的稳健性与可靠性。本文模型结构清晰、计算高效，可为乙醇偶合制备C4烯烃的实验设计提供定量参考。

**关键词：** C4烯烃；催化剂组合；岭回归；粒子群优化；平稳性检验；AR模型
